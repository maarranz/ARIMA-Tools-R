Overview and purpose

arimatools is the R port of the Python package ARIMA-Tools, developed for the Applied Time Series Econometrics (ATSE) course at Universidad Carlos III de Madrid. It complements forecast and stats with teaching-oriented tables, summaries, numerical forecasts, and figures.

This document describes the software/API. The ATSE course material provides the econometric theory; the Labs provide fuller worked examples and exercises. The package exposes the same 26 public functions as the Python version, with the same names, plus three outlier functions that are R-only for now. Models are fitted with forecast::Arima() (recommended), forecast::auto.arima() or stats::arima(), and every function that takes a fitted model accepts any of the three — including the output of auto_arima(), which in Python was a separate StatsForecast object.

Diagnostics have three layers: parameters and model structure, residual behavior, and model behavior (dynamics and parameter stability).

What R already provides

Several Python functions exist because Statsmodels lacks them. In R some have close equivalents, which the package wraps so that the API, tables and defaults stay the same as in Python:

arimatools Closest existing R tool Why the wrapper is kept
coefficient_diagnostics() lmtest::coeftest(), confint() One table with intervals
parameter_correlation() cov2cor(vcov(fit)) Same name as Python
ljung_box_test() Box.test(..., fitdf = p + q) Several lags, df check
plot_residual_diagnostics() forecast::checkresiduals(), tsdiag() ACF + PACF + LB p-values; tsdiag() does not adjust df
jarque_bera_test() tseries::jarque.bera.test() Adds skewness and kurtosis
dynamic_effects() ARMAtoMA() Includes the differencing polynomial
plot_inverse_roots() autoplot(fit) Common-root markers
auto_arima() forecast::auto.arima() Course defaults (BIC, nonseasonal, no approximation)
order_search() auto.arima(..., trace = TRUE) Returns the full table
plot_fan_chart() autoplot(forecast(fit)), fanplot Psi-weight intervals, nested bands

Root and common-root checks, the Wald test, recursive estimation and parameter-stability plots, model-comparison tables with HQIC, and the psi-weight forecast-error variance have no direct R counterpart.

Installation and loading

# install.packages("remotes")
remotes::install_github("maarranz/ARIMA-Tools-R")

Dependencies (digest, forecast, ggplot2, patchwork, zoo) are installed automatically. plotly is optional and only needed for interactive = TRUE; tsoutliers is needed only for detect_outliers().

library(forecast)
library(arimatools)

Small example used below

The data-generating process is a zero-mean ARMA(1,1), y[t] = 0.7*y[t-1] + eps[t] + 0.4*eps[t-1], with standard-normal innovations, stored as a monthly ts starting in January 2000. (R’s random-number generator differs from NumPy’s, so the series is not the one in the Python documentation.)

set.seed(12345)
y <- ts(arima.sim(list(ar = 0.7, ma = 0.4), n = 240, n.start = 100),
        start = c(2000, 1), frequency = 12)
fit <- Arima(y, order = c(1, 0, 1), include.mean = FALSE)

Run the blocks below in sequence in the same session. Tables are data frames that follow R/broom column conventions (term, estimate, std.error, statistic, p.value, conf.low, conf.high). Single-result tests and summaries are named lists that print as two columns; as.data.frame() turns them into tables (e.g. for knitr::kable()). Plotting functions return ggplot2 objects (or patchwork objects for stacked panels), which can be modified with the usual + syntax; interactive = TRUE returns a plotly widget instead.

Estimation and parameter diagnostics

Fit models with forecast::Arima(). coefficient_diagnostics() returns estimates, standard errors, z-statistics, asymptotic p-values, and confidence intervals (confidence = 0.95). parameter_correlation() returns the correlation matrix of the estimates. joint_significance() takes coefficient names and returns a joint Wald test against zero.

coefficients <- coefficient_diagnostics(fit)
correlations <- parameter_correlation(fit)
joint_test <- joint_significance(fit, parameters = c("ar1", "ma1"))
print(coefficients, digits = 4)

Coefficient names follow R: ar1, ma2, sar1, intercept, drift (Python: ar.L1, ma.L2, const, …); see names(coef(fit)). R does not estimate a covariance for sigma2, so it never appears in the correlation matrix (Python’s include_variance argument has no R equivalent). Standard errors come from the Hessian, which corresponds to cov_type = "approx" in Statsmodels; Statsmodels’ default is the outer product of gradients, so its standard errors differ slightly.

Model diagnostics

Parameters and model structure

root_diagnostics() tabulates AR/MA roots, moduli, and inverses (seasonal models use the multiplied polynomials). is_causal() and is_invertible() return TRUE/FALSE; root_summary() combines the root checks. Causality refers to the stationary AR component, not the level stationarity of an integrated series.

common_roots() reports AR–MA pairs within inverse-root distance tol = 0.05; exact_tol = 1e-10 separates numerically common from near-common pairs. plot_inverse_roots() draws the inverse roots and the unit circle, marking such pairs with a cross.

roots <- root_diagnostics(fit)
causal <- is_causal(fit)
invertible <- is_invertible(fit)
common <- common_roots(fit)
root_checks <- root_summary(fit)
root_plot <- plot_inverse_roots(fit)

Residual behavior

ljung_box_test() requires lags greater than p + q (plus P + Q in seasonal models) and reports adjusted degrees of freedom and p-values. residual_correlations() returns residual ACF/PACF values and approximate individual white-noise bounds; these bounds are not a joint test.

jarque_bera_test() returns the normality statistic, p-value, skewness, and conventional kurtosis. plot_residual_diagnostics() stacks residuals, ACF, PACF, and valid-lag Ljung–Box p-values in four panels.

ljung_box <- ljung_box_test(fit, lags = c(5, 10, 20))
residual_acf_pacf <- residual_correlations(fit, lags = 20)
normality <- jarque_bera_test(fit)
residual_plot <- plot_residual_diagnostics(fit, lags = 20)

R’s residuals() are standardized innovations, which differ from Statsmodels’ raw one-step errors in the first few observations; Ljung–Box and Jarque–Bera statistics can therefore differ slightly between the two packages on the same model.

Model comparison and selection

compare_models() accepts at least two fitted models, labelled by their order, by argument names (compare_models(a = fit1, b = fit2)) or by names. Its table includes the log likelihood, AIC, AICc, BIC, and HQIC, with k counting the innovation variance. Compare models for the same dependent variable and sample.

The two operations are kept separate. order_search() estimates and reports: it fits every order from zero to p_max/q_max, and differencing orders from d_min through d_max (both default to zero), and reports all four criteria and the convergence status. Rows are grouped by d and sorted by criterion within each d; it never ranks models across different d. If the default CSS-ML estimation fails for a candidate, exact ML is tried and the status says so. select_model() is the only function that chooses, and it does so only when the criteria are comparable: models with the same d (choose d first, with unit-root tests and graphs; if the table has several d, select_model() asks for d =), fitted to the same observations, converged, and with a genuine likelihood (CSS-only fits have NA criteria). For tables from compare_models(), which record each model’s sample window (start, end) and a fingerprint of its complete series (sample_id: every observation in order, missing-value positions and time attributes), “the same observations” means the same window and the same values, so models for y and log(y), or for two different windows with the same length, are not compared. Selection is not a diagnostic assessment.

alternative <- Arima(y, order = c(1, 0, 0), include.mean = FALSE)
comparison <- compare_models(fit, alternative, names = c("ARMA(1,1)", "AR(1)"))
search <- order_search(y, p_max = 2, q_max = 2, criterion = "BIC",
                       include.constant = FALSE)
selected <- select_model(search, criterion = "BIC")
# With several d in the grid, choose d first:
# select_model(order_search(y, d_min = 0, d_max = 1), "BIC", d = 0)
print(selected)

Deterministic terms are set with include.constant (passed to forecast::Arima()): NULL keeps forecast’s default (a mean when d = 0, nothing when d > 0, matching Statsmodels’ default trend); TRUE gives a mean when d = 0 and a drift when d = 1; FALSE none. Other forecast::Arima() arguments, such as method = "ML", can be passed through ....

auto_arima() calls forecast::auto.arima() — the original Hyndman–Khandakar implementation that StatsForecast ports — with the course defaults: nonseasonal, BIC, and no CSS approximation. It returns an ordinary Arima object that every other function accepts. auto_arima_summary() returns a compact summary, including its mean/drift interpretation.

automatic <- auto_arima(y, criterion = "BIC", max_p = 2, max_q = 2)
automatic_summary <- auto_arima_summary(automatic)
automatic_roots <- root_summary(automatic)

Dynamic effects and parameter stability

dynamic_effects() returns the psi weights of the fitted model and their cumulative sums, from horizon zero through horizon = 20. The differencing polynomial (ordinary and seasonal) is included, so a fitted random walk has a unit response at every horizon. plot_dynamic_effects() plots both series. Models with a Box–Cox transformation (lambda) are rejected, because their psi weights describe the transformed series.

recursive_estimation() takes the original series and an order c(p, d, q) and returns a long expanding-window table with estimates, standard errors, intervals, sample endpoints, and convergence status, plus the recursive innovation variance (sigma2, without interval). initial can be an observation count, a fraction between zero and one, or NULL (an automatic 10% rule subject to min_df = 20). Endpoints are dates for monthly, quarterly and annual ts objects and observation numbers for plain vectors. External regressors (xreg) and lambda are not supported; endpoints where estimation failed keep their error messages in attr(recursive, "failures").

effects <- dynamic_effects(fit, horizon = 12)
effects_plot <- plot_dynamic_effects(fit, horizon = 12)
recursive <- recursive_estimation(y, order = c(1, 0, 1), initial = 220,
                                  include.constant = FALSE)
stability_plot <- plot_parameter_stability(recursive, parameters = c("ar1", "ma1"),
                                           breakpoint = as.Date("2019-01-01"))

plot_parameter_stability() takes the recursive table. parameters = NULL displays all coefficients except sigma2. reference = TRUE adds full-sample estimates. An optional breakpoint (on the endpoint scale: a Date or an observation number) is only a graphical marker; it is not a structural-break test.

Forecasting

All four functions take a fitted model. steps = 20 is a positive integer, and level = 0.95 is a central normal-theory prediction-interval coverage strictly between zero and one.

  • forecast_error_variance() returns a numeric vector for horizons 1 through steps, computed from the full ARIMA psi weights, including ordinary/seasonal integration, on the original scale.
  • dynamic_forecast() returns a data frame with horizon, forecast, fev, se, lower and upper. These are single-origin forecasts: all horizons are made from the end of the sample, with unknown future innovations set to zero, and are not updated as new data arrive. Point forecasts come from forecast::forecast(); uncertainty from the psi-weight FEV.
  • plot_forecast() draws the observed series, the forecast, two unfilled interval boundary lines, and a forecast-origin marker.
  • plot_fan_chart() draws nested shaded central intervals, stronger centrally and fading outward, and the point forecast.
fev <- forecast_error_variance(fit, steps = 20)
fc <- dynamic_forecast(fit, steps = 20, level = 0.95)
forecast_plot <- plot_forecast(fit, steps = 20, level = 0.95, history = 50)
fan_plot <- plot_fan_chart(fit, steps = 20, history = 50)
print(head(fc), digits = 4)

The default fan levels are c(0.50, 0.70, 0.80, 0.90, 0.95, 0.99); custom levels must be distinct and strictly between zero and one, in any order. history = 50 shows the final 50 observations and history = NULL the whole sample.

custom_fan <- plot_fan_chart(fit, steps = 12, levels = c(0.95, 0.50, 0.80),
                             history = NULL)

The intervals are Gaussian and conditional on the estimated parameters and the selected model: parameter and model-selection uncertainty are not included. FEV treats past innovations as known, so the exact Kalman-filter variances of predict() can differ slightly in short samples. The innovation variance is fit$sigma2: forecast::Arima() reports the degrees-of-freedom-adjusted SSR / (n′ − number of coefficients), where n′ is the number of observations after differencing, whereas stats::arima() and Statsmodels report the ML estimate SSR / n′. Using fit$sigma2 keeps these intervals consistent with forecast(fit) for the same object.

Three cases are rejected with an explanation: models with external regressors other than drift (including outlier regressors); models with a Box–Cox transformation (lambda), whose point forecasts are on the original scale while the variances would be on the transformed scale; and series with missing values, where the assumption of known past innovations fails and the intervals would be too narrow (use forecast::forecast() in that case).

Outliers

Three outlier types are supported, for nonseasonal models: an additive outlier (AO) is 1 at its date and 0 elsewhere; a level shift (LS) is 1 from its date onwards; a temporary change (TC) is delta^(t - t0) from its date onwards (delta = 0.7 by default).

outlier_regressors() builds these regressors for dates you choose, for example from known historical events, to pass as xreg. Dates can be written "2020Q2", "2020:2", "2008M09", "2008-09-01", as Date objects, or as observation numbers through positions. Columns are named by type and period (AO2020Q2), so the usual tables and tests identify them.

X <- outlier_regressors(y, dates = c("2008M09", "2016M03"), types = c("LS", "AO"))
fit_dummies <- Arima(y, order = c(1, 0, 1), include.mean = FALSE, xreg = X)
dummy_table <- coefficient_diagnostics(fit_dummies)
dummy_test <- joint_significance(fit_dummies, colnames(X))

detect_outliers() runs the Chen–Liu (1993) procedure through tsoutliers::tso() and re-estimates the final model with forecast::Arima() and regressors from outlier_regressors(). The model can be a fitted nonseasonal model (order and mean or drift kept fixed), a series with order = c(p, d, q), or a series alone, in which case auto.arima chooses the order (BIC, nonseasonal). The critical value cval follows the tsoutliers rule (3 for n ≤ 50, 4 for n ≥ 450, linear in between) unless given. The result prints a dated table of outliers and contains the final model ($fit), the regressors, the combined effect and the adjusted series.

detected <- detect_outliers(fit)
detected$outliers
diagnostics_after <- ljung_box_test(detected$fit, lags = c(8, 12))
comparison_outliers <- compare_models(fit, detected$fit,
                                      names = c("No outliers", "Outliers"))

plot_outliers() draws the observed and outlier-adjusted series, with outlier dates marked by type, and the combined outlier effect. It accepts the output of detect_outliers() or any model fitted with regressors from outlier_regressors(), so automatic and hand-picked outliers can be shown side by side.

outlier_plot <- plot_outliers(detected)
dummy_plot <- plot_outliers(fit_dummies, title = "Hand-picked outliers")

Supported models. detect_outliers() handles univariate, nonseasonal ARIMA models of the series as given, with an optional mean (d = 0) or the built-in drift of forecast::Arima(..., include.drift = TRUE) (d ≤ 1). Transform the series yourself (logs, growth rates) before calling it. Models with explanatory variables (xreg), a Box–Cox transformation (lambda) or fixed coefficients are rejected, because the effects and the adjusted series would be defined on another scale or conditional on other variables, or the constraints would be lost. Argument names in ... are matched as tso() would match them, so abbreviations such as xr are caught too, and a regressor named drift is accepted only if it is exactly the built-in drift (a shifted or rescaled trend is rejected). plot_outliers() rejects lambda models; for a model fitted by hand it plots the AO/LS/TC columns and ignores any other regressors.

Warnings and convergence. Warnings from tso(), such as an iteration limit reached during the search, are passed on as one warning and kept in $warnings; they do not necessarily invalidate the result. If the final model did not converge, a warning is issued and $converged is FALSE. The printed summary flags both.

Interpretation. AO, LS and TC are estimated intervention components of the modelled series, not proof of a cause. Standard errors and z-statistics treat the selected dates, types and order as known, without adjusting for the search.

Dates. Dates are checked against the frequency of the series: "2020Q2" or "2020:2" for quarterly data, "2008M09" or "2008:9" for monthly data, 1990 for annual data, and Date objects for all three. An invalid period such as "2000Q5", or a monthly date on a quarterly series, is an error. Weekly and daily series need positions.

Detection currently uses tsoutliers; the arguments and output are defined independently of it so that the algorithm can later be replaced without changing code that uses these functions. Forecasting models with outlier regressors is not supported yet.

Compact API summary

fit is a model from forecast::Arima(), forecast::auto.arima() or stats::arima(). Plot functions accept interactive = TRUE (plotly); figure size is controlled by the chunk options (fig-width, fig-height) rather than by arguments.

Public call Return / contents
root_diagnostics(fit) data frame: AR/MA roots and inverses
is_causal(fit, tol = 1e-10) logical: AR causality
is_invertible(fit, tol = 1e-10) logical: MA invertibility
common_roots(fit, tol = 0.05, exact_tol = 1e-10) data frame: common/near-common root pairs
plot_inverse_roots(fit, tol = 0.05, exact_tol = 1e-10, title = "Inverse Roots", interactive = FALSE) ggplot: inverse roots
root_summary(fit, tol = 0.05, exact_tol = 1e-10) summary list: root checks
coefficient_diagnostics(fit, confidence = 0.95) data frame: estimates and inference
parameter_correlation(fit) matrix: parameter correlations
joint_significance(fit, parameters) summary list: joint Wald test
ljung_box_test(fit, lags) data frame: adjusted Ljung–Box tests
residual_correlations(fit, lags = 20, confidence = 0.95) data frame: residual ACF/PACF and bounds
plot_residual_diagnostics(fit, lags = 20, confidence = 0.95, title = "Residual Diagnostics", interactive = FALSE) patchwork: four residual panels
jarque_bera_test(fit) summary list: normality test and moments
dynamic_effects(fit, horizon = 20) data frame: effects and cumulative effects
plot_dynamic_effects(fit, horizon = 20, title = "Dynamic Effects of an Innovation", interactive = FALSE) patchwork: effects and cumulative effects
compare_models(..., names = NULL) data frame: likelihood and information criteria

recursive_estimation(y, order, initial = NULL, min_df = 20, confidence = 0.95, include.constant = NULL, ...) data frame: recursive estimates and fit status

auto_arima_summary(model) summary list: selected model
forecast_error_variance(fit, steps = 20) numeric vector: forecast-error variances
dynamic_forecast(fit, steps = 20, level = 0.95) data frame: forecast, fev, se, lower, upper

outlier_regressors(y, dates = NULL, types = "AO", delta = 0.7, positions = NULL) ts matrix: AO/LS/TC regressors named by type and date
detect_outliers(x, order = NULL, types = c("AO", "LS", "TC"), cval = NULL, delta = 0.7, include.constant = NULL, ...) outlier table, final model, effects, adjusted series
plot_outliers(x, title = "Outlier Effects", interactive = FALSE) patchwork: adjusted series and outlier effects

Full argument documentation is available in R with ?function_name (e.g. ?recursive_estimation).
